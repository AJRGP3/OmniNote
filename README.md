# OmniNote

OmniNote is a notebook for keeping class notes and readings together. It can use those materials to answer questions and make study guides, flashcards, and quizzes.

## What it does

- Create notebooks for different classes or topics
- Write notes and add text, documents, images, and web links as sources
- Ask questions about notes and sources
- Make study guides, flashcards, quizzes, and short reports
- Choose an answer length and, when available, search the web
- Switch between light and dark mode

Notes and notebooks are saved in the browser on the device where you use OmniNote.

## Run it

Open `index.html` in a modern browser. To publish the static site with GitHub Pages, place `index.html` in the repository’s main folder and enable Pages in the repository settings.

## Gemini API

OmniNote’s AI features connect directly to the Gemini API from the browser. The API key is entered in Settings and is not included in this repository. Don’t commit an API key to GitHub.

**Important:** Google’s Gemini API terms require API users to be 18 or older and restrict using the API in apps directed to, or likely to be accessed by, people under 18. OmniNote is designed as a student notebook, so don’t make its Gemini features available to students unless the API use complies with Google’s current terms: [Gemini API terms](https://ai.google.dev/gemini-api/terms).
